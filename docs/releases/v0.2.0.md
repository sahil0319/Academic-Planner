**Academic Planner 0.2.0** adds in-app updates, 12-hour times, credits with marks and GPA, and a
JSON import for courses and timetables. Your data carries over: install over the previous version
and open the app. The first time 0.2.0 opens an existing planner, it copies your database to a
`backups` folder next to it before upgrading it.

## New

### Updates inside the app
- A new **About** page shows the version, license, and where your data lives, and has a
  **Check for updates** button.
- When an update is available you see its release notes and choose **Install**. The app downloads
  it, checks its signature, installs it, and restarts. Nothing is installed without your click.
- The app also checks once when it starts. You can turn that off on the About page.
- Before any database upgrade the app saves a copy of your data in a `backups` folder, and a
  failed upgrade leaves your data as it was.
- Version 0.1.x cannot update itself. Install 0.2.0 by hand once, as described below. Later
  versions update from inside the app. Linux `.deb` installs open the release page instead of
  installing in place.

### Times shown as AM/PM
- Every time in the app reads like `9:30 AM`, including reminders and error messages.
- Time fields take digits plus a small AM/PM toggle: type `930` and choose PM for 9:30 PM. No colon
  is needed.
- Backups and CSV exports still store 24-hour times, so older backups keep working.

### Credits, marks, and GPA
- Each course can have **credits** (4, 3, 1.5 and so on). A course with credits has `100 × credits`
  total marks.
- A new **Rules** page holds your grading rules: how the marks are split between attendance,
  quizzes, mid, and final; how many quizzes count (for example best 3 of 4); and the attendance
  bands that turn your attendance into marks. There is a ready-made Theory set and a Lab set, and
  both are fully editable. The shipped numbers are examples, so check them against your
  university's rules.
- The grade scale (A+ at 80%, A at 75%, and so on) is editable on the same page.
- Enter your quiz and mid scores on the assessments. The course page shows your marks so far, your
  projected grade, and a **Needed in final** table: the score you need in the final for each
  grade.
- The Courses page shows your term GPA, labelled projected until every mark is in.
- Backups include the rules, marks, and credits. Backups made with 0.1.x restore with courses
  ungraded.

### Import courses and timetable from JSON
- On the Courses page, **Import** lets you paste a JSON document with your courses and weekly
  timetable. The app shows a preview of everything it will add or change, and the exact problem
  with the file if there is one, before you apply it.
- Re-importing the same file changes nothing. Courses are matched by code (ignoring case and
  spaces), courses missing from the file are never deleted, and timetable changes start from a
  date you choose, so past attendance stays as it is.
- A template and a ready-made prompt for any AI assistant are built in with Copy buttons, so you
  can turn a timetable picture or table into the right JSON. The same files are in `docs/import`
  in the repository.

## Download

| Your computer | File to download |
| --- | --- |
| Mac with Apple Silicon (M1 or later) | the `.dmg` file |
| Windows 10 or 11 (64-bit) | the `-setup.exe` file |
| Ubuntu, Debian, and related Linux | the `.deb` file |
| Other Linux distributions | the `.AppImage` file |

The other files (`latest.json`, the `.sig` files, and the `.app.tar.gz`) are used by in-app
updates; you do not need to download them. `THIRD-PARTY-NOTICES.html` lists the licenses of the
open-source libraries the app is built with.

## Installing or updating

The builds are not signed by Apple or Microsoft, so your system may warn you the first time:

- **macOS**: open the `.dmg` and drag Academic Planner to Applications, replacing the old copy.
  - If macOS says the app **is damaged and can't be opened**, it is not damaged. Click **Cancel**
    (not Move to Trash), then run this in Terminal:
    `xattr -dr com.apple.quarantine "/Applications/Academic Planner.app"`
  - If macOS says it cannot verify the developer, open System Settings → Privacy & Security and
    click **Open Anyway** (on older macOS, right-click the app and choose **Open**).
- **Windows**: run the installer; if SmartScreen appears, click **More info**, then **Run anyway**.
- **Linux**: `sudo apt install ./academic-planner_*_amd64.deb`, or make the AppImage executable with
  `chmod +x` and run it.

Your planner data stays where it was (the folder is shown on the About page). Full steps are in the
[README](https://github.com/sahil0319/Academic-Planner#download-and-install).

## Known limitations

- The macOS build is for Apple Silicon only; Intel Macs can build from source and get no in-app
  updates.
- Notifications appear only while the app is open.
- The installers are not code-signed, so first launches show a system warning. In-app updates are
  signed and verified separately.
- The grading defaults are examples and must be adjusted to your university's rules.
