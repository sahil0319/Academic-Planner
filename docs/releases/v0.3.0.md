**Academic Planner 0.3.0** has a new look, a Progress page, bi-weekly classes, exam periods, public
holidays, and confirmation pop-ups. Your data carries over. If you have 0.2.0 or 0.2.1, open
**About** and click **Check for updates**, then **Install**.

## New

### A new look
- Square corners, IBM Plex Sans text, and slightly larger text (15 px) throughout.
- The dark appearance now uses a calm blue-grey palette. The light appearance is white and grey.
- Status tags (Attended, Pending, and so on) are square and line up in one column.
- Text boxes keep a constant width while you type, and form columns line up.

### Pop-up confirmations
- Saving, adding, importing, deleting, or archiving now shows a small pop-up in the bottom-right
  corner, for example "Term saved." or "Deleted 2 courses." It has a cross button and a timer bar,
  and goes away by itself after 5 seconds.
- Errors still appear next to the thing that failed and stay until you fix them.
- On the Rules page, saving a rule set or the grade scale now confirms, and a failed save tells you
  to fix the rows marked in red.

### Progress page
- A new **Progress** page between Dashboard and Timetable shows how each course is going so far:
  attendance against your target, classes you can still miss, your marks, and your projected
  grade. Courses at risk come first.

### Terms
- The dashboard shows your term, with the dates and the current week ("Week 3 of 17").
- In **Settings**, a finished term can be archived. Its courses, attendance, and marks are kept and
  listed under **Past terms** with attendance and GPA. Then you can set up the next term.

### Bi-weekly classes
- A class can meet every other week. Tick **Bi-weekly** on the class time and say whether it meets
  this week. Those classes are labelled "Every other week", and **Move to next week** shifts one
  occurrence.
- The import file accepts a bi-weekly class, and backups keep it.

### Exam periods
- **Settings** has separate cards for **Mid exams** and **Final exams**. Exam days skip classes
  like holidays, and the dashboard calendar shows each kind in its own colour.
- Days you entered as holidays before this version stay holidays. You can re-enter exam weeks as
  exam periods.

### Public holidays
- **Settings** has a **Public holidays** card. The app loads your country's public holidays from
  Google's public holiday calendar, and you choose which ones to add as holidays.
- Your country comes from your computer's region setting. You can pick another country or turn it
  off. The app contacts the calendar once when it starts and when you change the country. If it
  cannot connect, it keeps what it loaded last time and offers **Retry**.

### Default attendance rule
- New rule sets start with this attendance scale: 95% and up earns 100% of the attendance marks,
  90% earns 80%, 85% earns 60%, 75% earns 20%, 70% earns 10%, and below that earns 0. A rule set
  you have already edited is not changed. Rule sets that still had the old example scale get the
  new one.

## Fixed
- The marks table no longer shows "-0.0" when a component has no marks yet.
- The appearance switch no longer leaves a gap, and it no longer covers content when a page is
  scrolled.

## Download

| Your computer | File to download |
| --- | --- |
| Mac with Apple Silicon (M1 or later) | the `.dmg` file |
| Windows 10 or 11 (64-bit) | the `-setup.exe` file |
| Ubuntu, Debian, and related Linux | the `.deb` file |
| Other Linux distributions | the `.AppImage` file |

The other files (`latest.json`, the `.sig` files, and the `.app.tar.gz`) are used by in-app
updates; you do not need to download them. `THIRD-PARTY-NOTICES.html` lists the licenses of the
open-source libraries the app is built with, including the IBM Plex Sans font.

## Installing or updating

- **From 0.2.0 or 0.2.1**: use **Check for updates** on the About page. Linux `.deb` installs open
  the release page instead; install the new `.deb` from there.
- **From 0.1.x**: install 0.3.0 by hand once, as described in the
  [README](https://github.com/sahil0319/Academic-Planner#download-and-install). Later versions
  update from inside the app.
- The first time 0.3.0 opens your data, it upgrades the database and first saves a backup copy of
  your old data in a `backups` folder next to it.

The builds are not signed by Apple or Microsoft, so a fresh install may show a system warning the
first time. The README explains how to open the app anyway. Your planner data stays where it was
(the folder is shown on the About page).

## Known limitations

- The macOS build is for Apple Silicon only; Intel Macs can build from source and get no in-app
  updates.
- Notifications appear only while the app is open.
- The installers are not code-signed, so first launches show a system warning. In-app updates are
  signed and verified separately.
- The grading defaults are examples and must be adjusted to your university's rules.
- The check box and switch controls keep a rounded shape, because the UI toolkit does not allow
  changing it.
- Public holidays need an internet connection the first time you pick a country.
