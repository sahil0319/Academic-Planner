The first release of **Academic Planner**: a quiet, local-first desktop app for keeping track of your
university term. Enter your term, holidays, courses, and weekly class times once; the app fills in
every class of the term, you mark each one as attended, absent, or cancelled, and it keeps your
attendance percentage per course and your assessment deadlines in view.

No account, no server, no tracking: all your data stays in one file on your own computer.

## What's in this release

### Dashboard
- **Below-target banner** for any course whose attendance has dropped under the minimum you set.
- **Awaiting attendance**: past classes you haven't marked yet, each with one-click
  Attended / Absent / Cancelled buttons.
- **Mini calendar** with Previous / Today / Next month. Today is circled, days with classes get a
  small dot, and days with an assessment due get a small square. Click any day to see its classes
  (with status buttons) and the assessments due that day; today is selected by default.
- **Next class**, **overdue**, and **upcoming** assessments, with the upcoming window you choose.

### Timetable
- A week view (Previous / Today / Next) with each day's classes.
- Mark a class, cancel it, or reschedule it to another date, time, and room; the original then reads
  "Rescheduled → November 5, 2026" and the makeup class counts like any other.
- A **Rules** tab for the weekly class times: add a slot, change one from a chosen date (past classes
  keep their old time and room), or end one.

### Courses
- Create, edit, archive, and unarchive courses, with an optional attendance target.
- Each course shows attended / absent / cancelled / pending counts, the attendance percentage
  (or "—" until something is marked), and every session of the term.
- Add a one-off makeup class.

### Assessments
- Quizzes, exams, assignments, and other work with due date and time, notes, and an optional
  reminder.
- Filter by upcoming, overdue, completed, or all; tick one off when it's done.

### Settings
- Term dates, and holidays as a single day or a whole date range with one label, which is how
  midterm and final exam weeks are entered, so they never count as missed classes.
- Class reminder lead time, upcoming window, and desktop notifications on or off.
- **Backup** to a JSON file and **Restore** from one; before every restore the app saves a copy of
  your current data in a `backups` folder next to the database.
- **Export** attendance and assessments as CSV files for any spreadsheet.

### Everywhere
- Dates are typed as **DD-MM-YYYY** and shown as "October 26, 2026".
- **Reminders**: while the app is open, a desktop notification before each class and before
  assessments that have a reminder set.
- Keyboard navigation: Tab reaches every button, and Enter or Space activates it.

## Installing

These builds are not signed, so your system will warn you the first time:

- **macOS**: open the `.dmg` and drag Academic Planner to Applications. On first launch, open
  System Settings → Privacy & Security and click **Open Anyway** (on older macOS, right-click the
  app and choose **Open**).
- **Windows**: when SmartScreen appears, click **More info**, then **Run anyway**.
- **Linux**: `sudo apt install ./academic-planner_*_amd64.deb`, or make the AppImage executable
  with `chmod +x` and run it.

Full steps are in the [README](https://github.com/sahil0319/Academic-Planner#download-and-install).

## Where your data lives

| System | Folder |
| --- | --- |
| macOS | `~/Library/Application Support/Academic-Planner/` |
| Windows | `%APPDATA%\Academic Planner\data\` |
| Linux | `~/.local/share/academicplanner/` |

The folder is shown in Settings. Uninstalling the app does not delete it.

## Known limitations

- The macOS build is for Apple Silicon only; Intel Macs can build from source.
- Notifications appear only while the app is open; there is no background service.
- One active term at a time, and no date picker: dates are typed.
- The installers are not code-signed.
