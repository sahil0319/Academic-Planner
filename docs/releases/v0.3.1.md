**Academic Planner 0.3.1** fixes text boxes that were too small to use in 0.3.0, and lets you export
your courses and timetable to share with another person. Your data carries over. If you have 0.3.0,
open **About** and click **Check for updates**, then **Install**.

## Fixed
- In 0.3.0, some text boxes could shrink to a few pixels wide, so you could not click them or type
  in them. The **Code** box when adding a course was the clearest case. Text boxes now share the
  width of their row evenly, never shrink below a usable size, and can be clicked anywhere, including
  at their edges.

## New

### Export your courses and timetable
- On the **Courses** page, next to **Import…**, there are two new buttons: **Copy JSON** and
  **Save JSON…**.
- Copy JSON puts your courses and weekly timetable on the clipboard. Save JSON… writes them to a
  file named `academic-planner-courses.json`. Either way, the other person pastes the text into
  **Courses → Import…** in their own Academic Planner, checks the preview, and applies it.
- Tick some courses in the list first to export only those. With none ticked, every course that is
  not archived is exported.
- The export holds your term name and dates, and for each course its code, name, credits, rule set
  name, instructor, room, attendance target, and current class times, including classes that meet
  every other week. It does not include notes, attendance, assessments, marks, or past class times.
- The other person needs rule sets with the same names as yours. **Theory** and **Lab** exist for
  everyone. If your course uses a custom rule set name, their import preview shows an error for
  that line, which they can fix by removing it.
- Import on the same day the file was exported, because "meets this week" for a class that meets
  every other week is counted from the day of the import.

## Download

| Your computer | File to download |
| --- | --- |
| Mac with Apple Silicon (M1 or later) | the `.dmg` file |
| Windows 10 or 11 (64-bit) | the `-setup.exe` file |
| Ubuntu, Debian, and related Linux | the `.deb` file |
| Other Linux distributions | the `.AppImage` file |

The other files (`latest.json`, the `.sig` files, and the `.app.tar.gz`) are used by in-app
updates; you do not need to download them. `THIRD-PARTY-NOTICES.html` lists the licenses of the
open-source libraries the app is built with.

## Installing or updating

- **From 0.2.0, 0.2.1, or 0.3.0**: use **Check for updates** on the About page. Linux `.deb`
  installs open the release page instead; install the new `.deb` from there.
- **From 0.1.x**: install 0.3.1 by hand once, as described in the
  [README](https://github.com/sahil0319/Academic-Planner#download-and-install). Later versions
  update from inside the app.

The builds are not signed by Apple or Microsoft, so a fresh install may show a system warning the
first time. The README explains how to open the app anyway. Your planner data stays where it was
(the folder is shown on the About page).

## Known limitations

- The macOS build is for Apple Silicon only; Intel Macs can build from source and get no in-app
  updates.
- Notifications appear only while the app is open.
- The installers are not code-signed, so first launches show a system warning. In-app updates are
  signed and verified separately.
- The grading defaults are examples and must be adjusted to your university's rules.
- The check box and switch controls keep a rounded shape, because the UI toolkit does not allow
  changing it.
- Public holidays need an internet connection the first time you pick a country.
